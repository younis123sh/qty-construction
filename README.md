# حصر كميات QOB

تطبيق ويب (PWA) لحساب كميات أعمال البناء والخرسانة والتشطيبات، ويعمل دون إنترنت، مع تسجيل دخول ومزامنة سحابية عبر Firebase.

الملفات:
- `index.html`: التطبيق كاملاً.
- `sw.js`: عامل الخدمة (التخزين المؤقت والعمل دون إنترنت).
- `manifest.webmanifest` والأيقونات: للتثبيت على الهاتف.
- `firestore.rules`: قواعد الحماية لقاعدة البيانات (تُنسخ إلى Firebase، انظر الدليل).

للتفاصيل والخطوات: `دليل-الربط-والنشر.md`.
